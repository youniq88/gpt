# Desktop Buddy

바탕화면에 띄워두는 립싱크 캐릭터. 마이크 음량에 맞춰 입이 움직입니다.
라이브 강의나 영상 녹화 때 화면 한쪽에 띄워두는 용도입니다.

## 실행 방법

```
npm install
npm start
```

또는 설치 후 `실행.bat` 을 더블클릭.

## 캐릭터 이미지

모든 이미지는 **같은 캔버스 크기의 투명 PNG** 로 맞춥니다.
캔버스 크기가 같으므로 위치 조정 없이 자동으로 겹쳐집니다.
레이어 순서: 배경 캐릭터(또는 동작) → 입 → 눈.

**부품 모드** (권장) — `base.png` 가 있으면 이 방식으로 동작:

| 파일 | 역할 |
|------|------|
| `base.png` | 배경 캐릭터 (입·눈 없는 전체 모습) |
| `motions/*.png` | 동작 이미지 (역시 입·눈 없음) — 재생 중에도 입·눈이 얹혀 립싱크·깜빡임 유지 |
| `mouth-closed.png` | 닫은 입 (부품) |
| `mouth-open.png` | 벌린 입 (부품) |
| `eyes-open.png` | 뜬 눈 (부품) |
| `eyes-closed.png` | 감은 눈 (부품) — 없으면 깜빡임 꺼짐 |

**손그림 떨림(라인 보일)** — `base2.png`/`base3.png` 가 있으면 배경
캐릭터가 0.17초마다 번갈아 나와 손으로 여러 번 그린 듯 떨린다.
눈·입 부품은 떨리지 않는다. 프레임은 자동 생성할 수 있다:

```
.\node_modules\electron\dist\electron.exe gen-jitter.js
```

(base.png 를 바꾼 뒤에도 위 명령 한 번이면 떨림 프레임이 다시 만들어진다)

**호환 모드** — `base.png` 가 없으면 예전 방식:
`mouth-closed.png`/`mouth-open.png` 를 전체 그림으로 취급하고,
동작 재생 중에는 전체가 동작 그림으로 바뀝니다.

## 입력 소스

조작판의 **[입력: 마이크 / PC 사운드]** 버튼으로 전환합니다.

- **마이크** — 내 목소리에 맞춰 입이 움직임
- **PC 사운드** — PC 에서 나는 소리(영상·음성 파일 등)에 맞춰 입이 움직임
  (윈도우 시스템 소리 루프백. 화면은 캡처하지 않고 소리만 사용)

## 동작(모션) 설정

동작은 **목소리를 확 높였을 때** 나옵니다 (랜덤으로 나오지 않음).
판정: 최근 0.2초 최고 음량 ÷ 최근 15초 평소 목소리의 상위 10% 음량 > 기준.

`motions` 폴더에 이미지를 넣고 조작판의 "동작" 칸에서 정합니다.

- **비중(%)** — 여러 동작이 있을 때 이 비율로 하나를 고름. 0 은 사용 안 함
- **유지 시간(초)** — 한 번 나오면 보여주는 시간
- **다음 동작까지 최소(초)** — 연달아 나오지 않도록 하는 대기 시간
- **큰 소리 기준(배)** — 평소의 몇 배가 되면 나올지. 기본 2.3.
  잘 안 나오면 낮추고, 평소 말에도 나오면 올린다.

눈 깜빡임은 1~3초 랜덤 간격으로 자동 실행됩니다 (`eyes-closed.png` 필요).

## 조작

- **조작판 창** — 실행하면 캐릭터와 별도로 뜨는 일반 창. 크기, 클릭 통과,
  크로마키, 입력 소스, 민감도, 동작 설정, 진단 숫자가 모두 여기 있다.
  캐릭터 창에는 그림만 보이므로 방송 화면에 UI 가 잡히지 않는다.
  닫아도 캐릭터는 계속 움직인다.
- **캐릭터 우클릭** — 조작판 다시 열기 (또는 트레이 메뉴 [조작판 열기])
- **휠** — 캐릭터 위에서 굴리면 크기 조절
- **드래그** — 위치 이동
- **트레이 아이콘 우클릭** — 조작판 열기, 크기 프리셋, 클릭 통과, 종료

크기·위치·민감도는 자동 저장되어 다음 실행 때 복원됩니다.

## 구성

| 파일 | 역할 |
|------|------|
| `main.js` | Electron 메인 (창, 트레이, 크기/설정 저장) |
| `index.html` | 캐릭터 렌더 + 마이크 음량 분석 + 립싱크 |
| `preload.js` | 렌더러 ↔ 메인 IPC 브리지 |
| `capture.js` | 개발용 렌더 캡처 스크립트 |

## 맥(macOS)에 설치하기

1. **Node.js 설치** — https://nodejs.org 에서 LTS 버전 `.pkg` 를 받아 설치.
2. 이 폴더를 통째로 맥에 복사 (`node_modules` 는 빼고 — 아래 설치 과정에서 새로 받는다).
3. 터미널에서:

```
cd ~/desktop-buddy
npm install
npm start
```

   또는 폴더 안의 `start-mac.command` 를 더블클릭 (처음 한 번은 `npm install` 도 자동으로 한다).
   "확인되지 않은 개발자" 경고가 뜨면 파일을 우클릭 → [열기] 를 선택.

4. 처음 실행하면 마이크 권한을 묻는다. 허용하지 않았다면
   [시스템 설정] → [개인정보 보호 및 보안] → [마이크] 에서 켠다.

### 맥에서 다른 점

- **PC 사운드 모드는 쓸 수 없다.** 맥은 시스템 소리를 앱이 직접 받을 수 없어서,
  BlackHole 같은 가상 오디오 장치를 따로 설치해야 한다. 마이크 모드는 그대로 된다.
- 독 아이콘은 숨겨지고, 메뉴막대 아이콘으로 조작한다.
- 화면이 깨지거나 투명 배경이 이상하면 GPU 가속을 켜고 실행: `NO_GPU=0 npm start`
